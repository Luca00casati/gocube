# Third-party notices

GoCube is built on the following software. These components are **not** covered by the GoCube
license (`LICENSE.md`); each is covered by its own license, whose full text ships with the game
(in-game: **Licenses** on the title screen) and is in the `licenses/` folder of the source.

| Component | License | Full text |
|---|---|---|
| [Godot Engine](https://godotengine.org) 4.7.2 | MIT | `licenses/godot.txt` |
| [godot-cpp](https://github.com/godotengine/godot-cpp) (compiled into the engine library) | MIT | `licenses/godot_cpp.txt` |
| Libraries bundled in the Godot engine (e.g. FreeType, ENet, mbedTLS, HarfBuzz, zstd, ...) | various (MIT, BSD, zlib, Apache-2.0, FTL, ...) | shown in-game from the engine's own copyright data |

Builds of GoCube must keep these notices. The in-game Licenses screen lists the engine's bundled
libraries using `Engine.get_copyright_info()` / `Engine.get_license_info()`, so the list always
matches the engine build actually used.

All GoCube textures are original (generated by `tools/gen_textures.py`).
